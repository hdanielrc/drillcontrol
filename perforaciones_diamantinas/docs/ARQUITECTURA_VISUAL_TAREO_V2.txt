╔══════════════════════════════════════════════════════════════════════════╗
║                      5. FLUJO COMPLETO (End-to-End)                      ║
╚══════════════════════════════════════════════════════════════════════════╝

    ┌──────────────────────────────────────────────────────────────┐
    │  ESCENARIO 1: PROYECCIÓN MENSUAL (Inicio de mes)            │
    └──────────────────────────────────────────────────────────────┘

    1️⃣  Usuario hace clic en "🔄 Generar Proyección"
          │
          ▼
    2️⃣  JavaScript envía AJAX a api_generar_proyeccion
          │
          ▼
    3️⃣  Vista valida permisos y llama a TareoService
          │
          ▼
    4️⃣  TareoService itera sobre trabajadores activos
          │
          ▼
    5️⃣  Por cada trabajador x cada día del mes:
          • Calcula estado según régimen (14x7, 20x10, etc.)
          • Crea registro AsistenciaDiaria con es_proyeccion=True
          │
          ▼
    6️⃣  bulk_create inserta 2,100+ registros (70 trab x 30 días)
          │
          ▼
    7️⃣  Retorna estadísticas JSON al frontend
          │
          ▼
    8️⃣  JavaScript muestra mensaje de éxito y recarga página
          │
          ▼
    9️⃣  Usuario ve matriz pre-llenada con proyección automática


    ┌──────────────────────────────────────────────────────────────┐
    │  ESCENARIO 2: CORRECCIÓN MANUAL (Durante el mes)            │
    └──────────────────────────────────────────────────────────────┘

    1️⃣  Usuario cambia dropdown de "TRABAJO" a "FALTA"
          │
          ▼
    2️⃣  JavaScript actualiza clase CSS (cambia color)
          │
          ▼
    3️⃣  Usuario hace clic en "💾 Guardar"
          │
          ▼
    4️⃣  Formulario envía POST con todos los cambios
          │
          ▼
    5️⃣  Vista parsea datos (formato: estado_trabajadorID_YYYY-MM-DD)
          │
          ▼
    6️⃣  TareoService.actualizar_masivo_desde_formset:
          • Identifica registros a actualizar vs crear
          • Marca es_proyeccion=False (ahora son correcciones)
          • Registra usuario y timestamp
          │
          ▼
    7️⃣  bulk_update actualiza múltiples registros en una query
          │
          ▼
    8️⃣  Vista redirige con mensaje de éxito
          │
          ▼
    9️⃣  Usuario ve matriz actualizada con indicador ✓ (corrección)
